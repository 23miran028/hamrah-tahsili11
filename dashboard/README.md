## 🎯 این پروژه چیست؟

یک **داشبورد تک‌صفحه‌ای (SPA)** برای دانشجویان که به آن‌ها کمک می‌کند:

- 📊 وضعیت تحصیلی خود را در یک نگاه ببینند
- 🧠 با برنامه‌ریز هوشمند، ترم‌های آینده را بچینند
- 🔗 پیش‌نیازها را به‌صورت خودکار بررسی کنند
- 🏆 با دستاوردها انگیزه بگیرند
- 💾 اطلاعات را به‌صورت JSON پشتیبان بگیرند
- 📱 روی موبایل، تبلت و دسکتاپ کار کنند

> **همه چیز آفلاین است.** هیچ داده‌ای به سرور فرستاده نمی‌شود و همه چیز در `localStorage` مرورگر خودت ذخیره می‌شود.

## 📁 ساختار پوشه‌ها

```
dashboard/
├── index.html              ← صفحه اصلی
│
├── css/                    ← استایل‌ها
│   ├── base.css            ← متغیرهای رنگ، تم‌ها، reset
│   ├── layout.css          ← topbar، تب‌ها، پنل‌ها، layout
│   ├── components.css      ← دکمه، pill، مودال، toast، جدول
│   └── responsive.css      ← موبایل + چاپ
│
└── js/                     ← منطق برنامه
    ├── data.js             ← داده اولیه (دروس، ترم‌ها، برنامه)
    ├── utils.js            ← توابع کمکی (fmt، esc، toast، ...)
    ├── state.js            ← وضعیت globale + ذخیره‌سازی
    ├── prereq.js           ← بررسی پیش‌نیاز + نرمال‌سازی نام
    ├── charts.js           ← رسم نمودارها با Canvas
    ├── render.js           ← ساخت HTML همه بخش‌ها
    ├── planner.js          ← برنامه‌ریز هوشمند ترم
    ├── modals.js           ← مودال‌ها، drawer، confirm
    ├── export.js           ← JSON / CSV / Import
    ├── cmdk.js             ← Command Palette (Ctrl+K)
    ├── events.js           ← همه رویدادهای کاربر
    └── main.js             ← راه‌اندازی اولیه
```

### ⚠️ ترتیب بارگذاری اسکریپت‌ها

ترتیب بارگذاری **مهم است** و نباید تغییر کند:

```text
data → utils → state → prereq → charts → render 
    → planner → modals → export → cmdk → events → main
```

چون همه در global scope کار می‌کنند (بدون ES module)، پروژه حتی با دابل‌کلیک روی `index.html` و بدون سرور هم اجرا می‌شود.

## 🚀 شروع سریع

### اجرا در مرورگر

1. پوشه را جایی روی کامپیوتر بگذار
2. روی `index.html` دابل‌کلیک کن
3. تمام! (بدون نیاز به `npm`، build، یا سرور)

اگر می‌خواهی تغییرات را بلافاصله ببینی:

```bash

python -m http.server 8000

# یا با Node.js
npx serve .

# یا با PHP
php -S localhost:8000
```

سپس در مرورگر برو به: `http://localhost:8000`

## 💾 ذخیره و پشتیبان‌گیری

### ذخیره خودکار

هر تغییری که می‌دهی **بلافاصله در `localStorage` مرورگر ذخیره می‌شود**. حتی اگر مرورگر را ببندی، اطلاعات باقی می‌ماند.

### پشتیبان JSON

با دکمهٔ **↓ پشتیبان** یک فایل `choice-unit-backup.json` دانلود می‌شود. این فایل شامل:

- `courses` — لیست کامل دروس
- `plan` — برنامه ترم‌ها
- `termSummary` و `dashboardTerms` — خلاصه‌ها
- `sourceSummary` — اعداد اصلی اکسل

### بازیابی

با دکمهٔ **↑ بازیابی** فایل JSON را انتخاب کن تا همه‌چیز جایگزین شود.

> ⚠️ **هشدار:** بازیابی همه داده‌های فعلی را جایگزین می‌کند. قبلش پشتیبان بگیر.

### خروجی CSV

دکمهٔ **▤ CSV** یک فایل Excel-compatible می‌سازد که در Excel و Google Sheets باز می‌شود (با BOM برای پشتیبانی از فارسی).

### بازگشت به حالت اولیه

از سایدبار: **↺ بازگردانی اولیه** — همه چیز به حالت اول برمی‌گردد.

## 🔧 راهنمای توسعه

### افزودن یک تب جدید

1. در `index.html` یک `<button class="tab" data-view="myView">` اضافه کن
2. یک `<section class="view" id="view-myView">` بساز
3. در `render.js` تابع `renderMyView()` بنویس و آن را در `renderAll()` صدا بزن
4. در `setView()` اگر نیاز به رسم دیرهنگام نمودار داری، شرط اضافه کن

```js
// نمونه
function renderMyView(){
  const el = $('myViewBody');
  el.innerHTML = `...`;
}
```

### افزودن یک نمودار

```js
// در charts.js
function drawMyChart(){
  const { ctx, w, h } = canvasSetup('myCanvas');
  // ... رسم با ctx
}
```

> 💡 نکته: `canvasSetup` خودش بر اساس `devicePixelRatio` تنظیم می‌کند (Retina-ready).

### افزودن فرمول بررسی پیش‌نیاز جدید

فایل `prereq.js` → تابع `checkPrereq`. الگوهای استثنا از split جدا می‌شوند:

```js
if (/هم\s*نیاز|ترم \d|گذراندن \d+|_\s*$/i.test(p)) return;
```

### افزودن یک دستاورد

فایل `render.js` → آرایه `achievements` در `renderAchievements`. هر آیتم یک شرط `unlocked` دارد:

```js
{
  id: 'myAch',
  icon: '🎓',
  name: 'نام',
  desc: 'توضیح',
  unlocked: x.something >= N
}
```

### افزودن یک فرمان به Command Palette

فایل `cmdk.js` → آرایه `cmdkCmds`:

```js
{
  icon: '🎯',
  label: 'نام فرمان',
  run: () => { /* کار */ }
}
```

## 🧪 تست تغییرات

### تست سریع

بعد از هر تغییر، صفحه را **رفرش** کن (`Ctrl+R` یا `Cmd+R`).

### اگر تغییرات CSS/JS نمی‌آید

- `Ctrl+Shift+R` (hard refresh) بزن
- یا در DevTools → Network → **Disable cache** را تیک بزن

### پاک کردن state

اگر می‌خواهی از صفر شروع کنی:

```js
// در Console مرورگر (F12)
localStorage.clear();
location.reload();
```

یا فقط state داده:

```js
localStorage.removeItem('choiceUnitDashboard.v2');
location.reload();
```

یا فقط تنظیمات ظاهری:

```js
localStorage.removeItem('choiceUnitDashboard.ui.v2');
location.reload();
```

## 🐛 عیب‌یابی سریع

| مشکل | راه‌حل |
|:---|:---|
| داده‌ای ذخیره نمی‌شود | حالت Private/Incognito؟ `localStorage` آن‌جا غیرفعال است |

| روی موبایل چیزی دیده نمی‌شود | تب‌های بیشتر در دکمهٔ «⋯ بیشتر» هستند |

## 🧭 قواعد کدنویسی

### نام‌گذاری

| مورد | قاعده | نمونه |
|:---|:---|:---|
| متغیرها و توابع | `camelCase` | `totalUnits` |
| ثابت‌های سراسری | `UPPER_SNAKE` | `TYPE_NAMES` |
| فایل‌ها | `kebab-case` یا `single.js` | `data.js` |

### زبان توابع

```js
renderCourses()    // توابع رندر با render شروع می‌شوند
drawCharts()       // توابع رسم با draw شروع می‌شوند
checkPrereq()      // توابع بررسی با check یا is
```

### ذخیره HTML

همه‌جا از `esc()` برای escape کردن مقادیر استفاده کن — جلوگیری از XSS:

```js
`<td>${esc(c.name)}</td>`
```

### متغیرهای state

state در `state.js` تعریف شده و در همهٔ فایل‌ها مستقیماً قابل خواندن/نوشتن است. اگر مقدارِ کلیدی را عوض می‌کنی، بعدش `renderAll()` یا `persist()` صدا بزن.

## 📊 داده اولیه (SOURCE)

داده در `data.js` قرار دارد و شامل:

| کلید | توضیح |
|:---|:---|
| `courses` | لیست ۶۲ درس با وضعیت، ترم، پیش‌نیاز و ... |

| `dashboardTerms` | بار ترم‌ها از شیت Dashboard |

> 💡 اگر می‌خواهی داده اولیه را عوض کنی، فقط این فایل را ویرایش کن. برای بازگرداندن به این حالت از دکمهٔ «↺ بازگردانی اولیه» استفاده کن.

## 🚦 نسخه‌بندی

فرمت داده در `localStorage` با کلید زیر ذخیره می‌شود:

```text
choiceUnitDashboard.v2      ← داده اصلی
choiceUnitDashboard.ui.v2   ← تنظیمات ظاهر
```

اگر در آینده ساختار داده عوض شود، کلید را به `v3` تغییر بده و **migration** بنویس در `loadState()`:

```js
function loadState(){
  // مهاجرت از v2 به v3
  const old = JSON.parse(localStorage.getItem('choiceUnitDashboard.v2') || 'null');
  if (old) { /* تبدیل */ return converted; }
  // ...
}
```

## 📝 تغییرات مهم نسخه فعلی

- 🆕 **نرمال‌سازی نام پیش‌نیازها** (اعداد فارسی/عربی، ی و ک عربی) — هشدارهای «آماده» حالا واقعی هستند
- 🆕 **فایل‌ها به ماژول‌های مستقل شکسته شدند** — توسعه آسان‌تر
- 🆕 حذف `@font-face` معیوب
- 🆕 یکسان‌سازی فونت Canvas با `Estedad`
- 🆕 چاپ همه بخش‌ها با `page-break` (نه فقط تب فعال)

## 📞 کمک

اگر جایی گیر کردی:

1. کنسول مرورگر را باز کن (`F12`) و خطا را بخوان
